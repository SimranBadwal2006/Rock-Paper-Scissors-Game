# Rock Paper Scissors Game 🎮

A fun and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

## Features
- User vs Computer gameplay
- Random computer choices
- Score tracking
- Responsive UI
- Interactive animations and effects

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run

```bash
Open index.html
```
